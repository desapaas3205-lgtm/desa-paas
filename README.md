# 🌐 Website Resmi Pemerintah Desa Paas
**Kecamatan Pameungpeuk, Kabupaten Garut, Jawa Barat**  
*Slogan: "Menuju Desa Mandiri, Sejahtera, dan Berbudaya"*

Selamat datang! Proyek ini adalah website resmi untuk **Desa Paas**, dirancang dengan arsitektur web modern yang **100% GRATIS** untuk dioperasikan sekarang, serta **sangat mudah dihubungkan dengan domain resmi desa (`paas.desa.id`)** dan hosting resmi begitu anggaran desa sudah turun.

## 📌 Fitur Unggulan Website

1. **🏛️ Beranda Lengkap & Modern**:
   - Identitas resmi Desa Paas, Pameungpeuk, Garut.
   - Sambutan resmi Kepala Desa (**Bapak Agus Zenal**).
   - Indikator Status Kantor Live (Menampilkan status *Kantor Buka / Tutup* otomatis sesuai jam kerja 07:30 - 15:30 WIB).
   - Akses cepat layanan administrasi surat menyurat warga.
   - Peta lokasi kantor desa interaktif (Google Maps Pameungpeuk).

2. **📜 Visi, Misi & Sejarah Desa**:
   - Visi dan 6 Misi pembangunan Desa Paas.
   - Sejarah asal-usul nama "Paas" dari jalur perjumpaan warga dan perlintasan pesisir Garut Selatan.
   - Profil luas wilayah 1,95 km² (195 ha).

3. **👥 Pemerintahan & Struktur Organisasi**:
   - Menampilkan susunan aparatur desa:
     - **Kepala Desa**: Agus Zenal
     - **Sekretaris Desa**: Iwan Setian
     - **Kaur Keuangan**: Yana Suryana
     - **Kaur Perencanaan**: Otang Gunawan
     - **Kaur Umum**: Inta Siti A.S
     - **Kasi Pemerintahan**: Dendi Rachman Satria
     - **Kasi Pelayanan**: Yuliansari
     - **Kasi Kesejahteraan**: Neuis Sulastri
     - **Kepala Dusun 1**: Galih Mukhlis
     - **Kepala Dusun 2**: Deni Sudian
     - **Kepala Dusun 3**: Sutendi
   - Lembaga Mitra: BPD, PKK, Karang Taruna, Satlinmas.

4. **📑 Layanan Surat Mandiri Online (WhatsApp Dispatcher)**:
   - Warga dapat mengajukan permohonan surat secara mandiri dari HP (KTP/KK, Domisili, SKTM, SKU Usaha, SKCK, Kematian, Nikah).
   - Dilengkapi checklist syarat berkas yang harus dibawa ke kantor.
   - Sistem otomatis membuat draf permohonan resmi dan membuka WhatsApp ke nomor admin pelayanan desa.

5. **📊 Data Kependudukan & Demografi**:
   - Total Penduduk: **6.683 Jiwa** (Laki-laki: 3.353, Perempuan: 3.330).
   - Kepala Keluarga (KK): **1.798 KK**.
   - Pembagian 3 wilayah kedusunan dan mata pencaharian warga.

6. **🌾 Potensi Desa & Lapak UMKM**:
   - Pertanian sawah teknis, perdagangan & UMKM olahan pesisir/singkong, perkebunan kelapa/pisang, peternakan domba Garut & unggas.
   - Etalase produk UMKM warga lokal.

7. **📰 Kabar Desa & Agenda Pembangunan**:
   - Penyaluran BLT Dana Desa (BLT-DD) bagi KPM.
   - Peningkatan jalan lingkungan rabat beton & normalisasi drainase.
   - Pelayanan terpadu Posyandu & penanganan stunting balita.
   - Musrenbangdes penjaringan usulan RKPDes.
   - Modal pop-up baca artikel berita lengkap.

8. **📢 Saluran Pengaduan & Aspirasi Warga**:
   - Formulir pesan aspirasi warga yang langsung terkirim ke WhatsApp perangkat desa.

## 🚀 Cara Melihat Website di Komputer Anda Sekarang

Ada 2 cara sangat mudah:

### Cara 1: Buka Langsung (Tanpa Aplikasi Tambahan)
1. Buka folder `c:\Users\ASUS\Downloads\Website_Desa_Paas`.
2. Klik ganda file **`index.html`**.
3. Website akan langsung terbuka di Google Chrome, Microsoft Edge, atau browser pilihan Anda.

### Cara 2: Menjalankan Server Lokal (Opsional)
Buka terminal / PowerShell di folder ini, lalu ketik salah satu perintah:
```bash
# Menggunakan Python:
python -m http.server 3000

# Atau menggunakan Node / npx:
npx serve .
```
Lalu buka browser di `http://localhost:3000`.

## ☁️ Cara Meng-Online-kan Website 100% GRATIS Sekarang

Agar website ini bisa diakses oleh warga Desa Paas dari smartphone mereka di mana saja tanpa biaya sepeser pun:

### Opsi A (Paling Mudah: 1 Menit via Netlify Drop - Tanpa Coding)
1. Kunjungi situs: **[https://app.netlify.com/drop](https://app.netlify.com/drop)** (daftar akun gratis jika belum punya).
2. Seret (drag & drop) folder `Website_Desa_Paas` ke halaman tersebut.
3. Tunggu beberapa detik, website Anda langsung online dan mendapatkan alamat gratis seperti `https://desa-paas.netlify.app`!
4. Bagikan link tersebut ke warga atau perangkat desa untuk ditinjau.

### Opsi B (via Vercel)
1. Buka **[https://vercel.com](https://vercel.com)** dan buat akun gratis.
2. Unggah folder ini ke repository GitHub atau gunakan Vercel CLI (`npx vercel`).
3. Website Anda langsung online dengan domain gratis seperti `https://desa-paas.vercel.app`.

### Opsi C (via Cloudflare Pages / GitHub Pages)
- Keduanya menyediakan hosting gratis selamanya dengan bandwidth tanpa batas dan perlindungan keamanan SSL gratis.

## 🏷️ Panduan Ketika Anggaran Desa Sudah Turun (Beli Domain & Hosting Resmi)

Begitu anggaran Dana Desa atau alokasi APBDes sudah dicairkan:

### 1. Membeli Domain Resmi Desa (`desa.id`)
- Domain resmi instansi desa di Indonesia adalah **`.desa.id`** (dikelola oleh PANDI dan Kominfo).
- **Syarat Pendaftaran Domain `.desa.id`**:
  1. Surat Permohonan Domain bertandatangan Kepala Desa / Sekretaris Desa.
  2. Surat Kuasa (jika dikuasakan kepada perangkat desa yang mengurus).
  3. KTP Kepala Desa / Penerima Kuasa.
  4. SK Pengangkatan Kepala Desa / Perangkat Desa yang masih berlaku.
- **Biaya**: Sangat terjangkau, rata-rata **Rp 55.000 s/d Rp 100.000 per tahun**.
- Anda bisa mendaftarkannya di registrar resmi seperti Rumahweb, Niagahoster, DomaiNesia, JagoanHosting, atau Cloudkilat.

### 2. Cara Menghubungkan Domain `paas.desa.id`:
- **Tips Hemat Anggaran**: Anda **TIDAK HARUS** menyewa hosting mahal bulanan! Anda bisa tetap menggunakan hosting modern gratis (Vercel / Netlify / Cloudflare Pages) dan cukup mengarahkan DNS domain `paas.desa.id` (CNAME & A Record) ke hosting tersebut secara **GRATIS**.
- **Jika Pemdes Ingin Hosting cPanel Mandiri**:
  1. Sewa paket hosting cPanel (misalnya Rp 150.000 - Rp 300.000 / tahun).
  2. Buka cPanel -> **File Manager** -> folder `public_html`.
  3. Unggah (upload) seluruh isi folder website ini ke `public_html`.
  4. Selesai! Website desa Anda langsung aktif di `https://paas.desa.id`.

## ⚙️ Cara Mengubah Nomor WhatsApp & Kontak Pelayanan

Untuk mengganti nomor WhatsApp tujuan layanan dan pengaduan warga:
1. Buka file **`assets/js/main.js`**.
2. Pada baris paling atas, ganti konfigurasi nomor telepon:
   ```javascript
   const DESA_CONFIG = {
     namaDesa: "Desa Paas",
     kecamatan: "Pameungpeuk",
     kabupaten: "Garut",
     provinsi: "Jawa Barat",
     kodepos: "44175",
     whatsappAdmin: "6282123456789", // Ganti dengan nomor WhatsApp aktif desa Paas (awali dengan 62)
     emailDesa: "pemdespaas.garut@gmail.com",
     ...
   };
   ```
3. Simpan file. Semua tombol WhatsApp di website otomatis akan terhubung ke nomor baru tersebut.
